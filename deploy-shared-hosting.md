### Shared Hosting (cPanel / Plesk style)

- **1. Prepare Laravel for production**
  - In `backend/`:
    ```bash
    composer install --no-dev --optimize-autoloader
    cp .env.example .env   # then edit .env with your production settings
    php artisan key:generate
    php artisan migrate --force
    php artisan config:cache
    php artisan route:cache
    npm install && npm run build  # Build frontend assets (CSS/JS)
    ```
    - Make sure `storage` and `bootstrap/cache` directories are writable:
      ```bash
      chmod -R 775 storage bootstrap/cache
      ```

- **2. Upload files to the server**
  - Upload the entire `backend` folder to `/home/USER/worktracker.mydomain.com/`
  - Ensure all files are uploaded, including:
    - `app/`, `bootstrap/`, `config/`, `database/`, `public/`, `resources/`, `routes/`, `storage/`, `vendor/`
    - `.env` file (with your production settings)
    - All other Laravel files

- **3. Point the document root**
  - **In cPanel:**
    1. Go to **Subdomains** (or **Addon Domains** if using a full domain)
    2. Find your subdomain/domain (e.g., `worktracker.mydomain.com`)
    3. Click **Change** or **Edit** next to the document root
    4. Set the document root to `/home/USER/worktracker.mydomain.com/public`
    5. Click **Change** to save
  
  - **In Plesk:**
    1. Go to **Domains** → select your domain/subdomain
    2. Click **Hosting Settings**
    3. Under **Document root**, change it to `/home/USER/worktracker.mydomain.com/public`
    4. Click **OK** to save

- **4. Set file permissions**
  - Make sure these directories are writable by the web server:
    ```bash
    chmod -R 775 storage bootstrap/cache
    ```
  - If your host uses a specific user/group, you may need to set ownership:
    ```bash
    chown -R USER:www-data storage bootstrap/cache
    ```
    (Replace `USER` with your hosting account username)

- **5. Configure .env file**
  - Edit `/home/USER/worktracker.mydomain.com/.env` with your production settings:
    ```env
    APP_NAME="Work Tracker"
    APP_ENV=production
    APP_KEY=base64:... (generated by key:generate)
    APP_DEBUG=false
    APP_URL=https://worktracker.mydomain.com
    
    DB_CONNECTION=mysql  # or your database type
    DB_HOST=localhost
    DB_PORT=3306
    DB_DATABASE=your_database_name
    DB_USERNAME=your_database_user
    DB_PASSWORD=your_database_password
    ```

- **6. Test the installation**
  - Visit `https://worktracker.mydomain.com` in your browser
  - You should see the dashboard (login required for full functionality)
  - If you see errors, check:
    - File permissions on `storage/` and `bootstrap/cache/`
    - `.env` file configuration
    - PHP version (Laravel 12 requires PHP 8.2+)
    - Required PHP extensions are installed

## Benefits of Blade-only deployment

- ✅ **Single deployment** - Just upload Laravel files, no separate frontend build
- ✅ **No CORS issues** - Everything served from the same origin
- ✅ **Simpler configuration** - Standard Laravel deployment
- ✅ **Works on any shared hosting** - No special requirements
- ✅ **Better SEO** - Server-rendered HTML
- ✅ **Easier maintenance** - One codebase, one deployment
